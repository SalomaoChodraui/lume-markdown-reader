O Lume agora é um app nativo para Mac, escrito em SwiftUI.

- menus em português com atalhos para tudo, e Ajustes em ⌘,
- arquivos da pasta na barra lateral; sumário e propriedades no painel da direita
- o tema Automático segue o modo claro ou escuro do Mac
- links wiki dentro de código ficam como texto, e avisos `> [!NOTE]` aparecem formatados
- fechar ou sair com alterações pergunta se você quer salvar
- editor com Desfazer, busca e números de linha
- reabre o último documento no ponto em que você parou

Binário universal para Apple Silicon e Intel, assinado com Developer ID e
notarizado pela Apple. Requer macOS 14 Sonoma ou superior. Para macOS 12 e 13,
use o [Lume 1.2.1](https://github.com/salo-adm-camelie/lume-markdown-reader/releases/tag/v1.2.1).
