# Atalhos

| Ação | Atalho |
| --- | --- |
| Abrir arquivo ou pasta | ⌘O |
| Salvar / Salvar como | ⌘S / ⇧⌘S |
| Imprimir ou salvar em PDF | ⌘P |
| Buscar no documento | ⌘F |
| Próxima / anterior ocorrência | ⌘G / ⇧⌘G |
| Buscar em todos os arquivos | ⌥⌘F |
| Editar Markdown / voltar à leitura | ⇧⌘E |
| Mostrar números de linha | ⌥⌘L |
| Aumentar / diminuir texto | ⌘+ / ⌘- |
| Tamanho real | ⌘0 |
| Voltar / avançar | ⌘[ / ⌘] |
| Mostrar ou ocultar arquivos | ⌃⌘S |
| Mostrar ou ocultar sumário | ⌃⌘I |
| Ajustes | ⌘, |
| Fechar a busca | Esc |

## Dica

Arraste qualquer arquivo `.md` ou pasta para a janela. Se abriu uma pasta, use os links `[[wiki]]` para passear entre as notas.

Voltar para [[Boas-vindas]].
