# Changelog

Todas as mudanças relevantes do Lume serão registradas aqui.

## 1.2.1 — 2026-08-01

Primeira versão pública.

### Destaques

- aplicativo nativo para macOS com associação de arquivos Markdown
- abertura de arquivos e pastas, arrastar e soltar e atualização automática
- busca global por nome e conteúdo e busca com destaques no documento atual
- histórico de documentos recentes mantido somente no dispositivo
- links wiki, links relativos, sumário automático e YAML front matter
- temas Papel, Sépia, E-ink, Noite, Meia-noite e Terminal
- personalização completa das cores do modo Terminal
- coluna de leitura responsiva, zoom, impressão/PDF e cópia de código
- correções de janela, laterais recolhíveis e espaçamentos do cabeçalho
